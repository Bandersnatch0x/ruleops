# Make the ontology authoritative and compile it for runtime

The ERF Ontology is the Control Plane's authoritative semantic model: its concept layer defines domain meaning and its instance layer gives governed assets stable IRIs and immutable revisions. Execution never depends on open-world reasoning; a fixed ontology revision is compiled into closed-world contracts, validated, digested and signed, and every RuleRelease, Policy and Evidence artifact records that revision.
