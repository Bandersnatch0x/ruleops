# Use versioned semantic Finding fingerprints

Finding fingerprints are versioned and primarily derive from RuleIntent identity, Scenario identity, normalized repository-relative path and a Semantic Anchor; severity, message text, RuleRelease version and Backend implementation version are excluded. Move or copy associations require explainable remapping evidence, ambiguous mappings remain AMBIGUOUS, and fingerprint algorithm changes require migration mappings plus a same-commit double scan.
