# Version ontologies with IRIs and content digests

An ontology series has a stable ontology IRI, each immutable Ontology Revision has its own version IRI, and canonical content digest is the supply-chain identity; SemVer is not used as content identity. Changes are classified as additive, constraint-tightening, behavioral or breaking, and every non-additive change triggers impact analysis and revalidation while old revisions remain auditable.
