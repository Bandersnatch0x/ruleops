# 代理文档导航

需要定位工作规则、验收入口或已有工具说明时，从本页进入。本页只做导航，不新增权威、阶段或门禁；冲突时回到[仓库工作规则](../../AGENTS.md)及其指定权威。

## 按任务找入口

| 需要做什么 | 阅读入口 |
| --- | --- |
| 确认领域术语与当前产品边界 | [领域上下文](../../CONTEXT.md)、[裁决记录](../adr/)、[领域文档读取约定](domain.md) |
| 判断开发阶段、执行与验收职责 | [开发工作流](dev-workflow.md) |
| 操作票据或处理待裁事项 | [票据惯例](issue-tracker.md)、[分诊标签](triage-labels.md) |
| 理解实现、运行系统、执行测试、使用产品 | [项目指南](../guide/README.md) |
| 执行或审阅端到端验收 | [E2E 测试套件](../e2e/README.md) |
| 评估本地提交检查及安装边界 | [提交检查说明](../agent-commit-hook.md) |

## 目录与现有实现

| 内容 | 位置与说明 |
| --- | --- |
| 仓库规则与宿主入口 | [AGENTS.md](../../AGENTS.md) 为规则入口；[CLAUDE.md](../../CLAUDE.md) 薄引用该入口 |
| 代理工作约定 | 本目录；阶段命令绑定只在[开发工作流](dev-workflow.md)维护 |
| 持久文档与临时证据 | 按仓库规则分别放 `docs/` 与 `.scratch/`；临时参考仓和任务报告不随版本分发 |
| 业务实现与机器规格 | 现有 `runtime/`、`control-plane/`、`contracts/`、`specs/` 等不是文档临时产物；边界见[领域上下文](../../CONTEXT.md) |
| 本地提交检查 | 已有 [Git hook](../../scripts/hooks/pre-commit) 调用[共享检查实现](../../scripts/agent-commit-check.py)；安装及非权威性质以[专项说明](../agent-commit-hook.md)为准 |
| 项目技能与宿主配置 | 本导航不安装技能、不创建宿主配置、不更改 Git hook 设置；新增集成仍需按工作流确定范围 |

导航没有赋予迁移、重命名、删除历史文件或覆盖既有约定的许可。需要结构调整时，先列出引用影响与待裁事项，再按批准范围实施。
